Two design directions for mcolors

Both directions use the same paint swatches, so those come first. Then you'll see Direction A (Build Sheet), Direction B (Paint Booth) and a table comparing them. The last section mixes the two. The numbers are from the live registry today: 255 builds, 70 paints and 11 countries.

Paint swatches by finish

Each swatch is drawn in CSS from the paint's hex value and its finish. There are no images, so it adds nothing to load time or server work. The same swatch works as a 22px dot in the entries table and as a large panel on a color page.

In this mockup the finish comes from the paint's name. If the name says Metallic, Pearl or Frozen, it gets that finish, and everything else is drawn as solid. Plenty of metallic paints don't say so in their name, so the real version needs a finish field in colors.ts, filled in by hand.

The hex values are the ones the site uses now. They're close to each paint, but they aren't BMW's official values.

Direction A

Build Sheet

This direction looks like a spec sheet, with a graphite background, wide display type and monospaced numbers. Each car's specs are laid out the way a window sticker lists them, and the M stripe separates sections.

The home page starts with one strip per paint, sorted by color. The more builds a paint has, the wider its strip. Click a strip to load that paint into the color page below.

This mockup only has year and drivetrain data for Twilight Purple. The real page shows them for every paint.

Direction B

Paint Booth

This direction looks like a dark showroom with one overhead light. It uses condensed italic type and gives the paint most of the space. The home page opens with a fan of paint cards for the 12 most-registered colors. The colors page uses large tiles that you can sort and filter.

A + B

The mix

I split the two by what each page is for. Most of the site is tables, charts and the map, where people read numbers, so A's type and layout cover the whole site. B's lit-paint look is for the places where the paint itself is the point. That means the paint names, the home page strips, the colors page, the swatch on each color page and the image people see when a link is shared.

Two display fonts would look messy, so B's condensed italic only sets paint names, like the name printed on a paint chip.
